유튜브 악보 PDF 변환기 사용 방법
================================

1. 설치
   youtube-score-pdf-setup-x.x.x.exe 를 실행하면 설치됩니다.
   설치가 끝나면 바탕화면과 시작 메뉴에 "유튜브 악보 PDF 변환기" 가 생깁니다.
   (윈도우가 "이 앱은 알 수 없는 게시자입니다" 라고 물으면 [추가 정보] -> [실행]
    을 눌러 주세요. 코드 서명 인증서가 없는 프로그램에는 항상 나오는 안내입니다.)

2. 사용
   1) 프로그램을 실행합니다.
   2) 유튜브 링크를 한 줄에 하나씩 붙여넣습니다. 여러 개를 넣으면 위에서부터
      차례대로 변환합니다. 개수 제한은 없습니다.
   3) PDF 제목은 비워두면 유튜브 영상 제목을 그대로 씁니다.
   4) 저장 폴더를 고르고 [변환 시작] 을 누릅니다.
   5) 끝나면 [폴더 열기] 로 PDF 를 바로 확인할 수 있습니다.

3. 걸리는 시간
   3~4분 길이 영상 한 개에 보통 2~4분 정도 걸립니다. 영상을 내려받고, 화면에서
   악보가 나온 장면을 모두 모아 겹친 다음 한 장의 A4 로 정리하기 때문입니다.

4. 이런 경우에는 변환이 안 됩니다
   - 비공개, 삭제된 영상, 로그인이 필요한 영상
   - 화면에 악보가 보이지 않는 영상
   - 악보가 한 줄로 좌우로 계속 흘러가는 영상
     악보가 한 화면씩 멈춰서 넘어가는 방식이어야 변환할 수 있습니다.
     흘러가는 영상은 프로그램이 알아서 확인하고 변환을 멈춥니다.
   변환이 안 되는 링크가 있어도 나머지 링크는 계속 변환합니다. 어떤 링크가 왜
   실패했는지는 창 아래 "진행 내용" 에 한국어로 표시됩니다.

5. 설치와 복사에 대해
   - 여러 대의 PC 에 설치해서 쓰셔도 됩니다. 대수 제한은 없습니다.
   - 다만 PC 마다 이 설치 파일을 한 번 실행해 주셔야 합니다.
     설치가 끝난 폴더를 통째로 복사해서 다른 컴퓨터에 붙여넣으면 실행되지
     않고 "정상 설치된 프로그램이 아닙니다" 라고 표시됩니다. 그 컴퓨터에서도
     설치 파일을 한 번 실행하시면 바로 정상 동작합니다.
   - 같은 PC 안에서 설치 폴더를 옮기거나 이름을 바꾸는 것은 상관없습니다.

6. 알아두실 점
   - 프로그램이 켜져 있는 동안 새 버전이 나오면 자동으로 업데이트됩니다.
   - 악보는 영상 업로더가 만든 편곡입니다. 개인 연습 범위에서 사용해 주세요.

문의: 크몽 메시지로 연락 주세요.
